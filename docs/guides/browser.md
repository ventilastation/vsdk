# Play in the browser

[Open the web emulator](https://ventilastation.protocultura.net/emulator/).
It runs the console’s MicroPython games in your browser, with keyboard, gamepad
and touch controls. Pick a game from the launcher and press A to begin.

| Action | Player 1 | Player 2 |
| --- | --- | --- |
| Left / Right | Arrow keys | H / L |
| A | Space | Z |
| B | O | X |
| X | P | C |
| Y / Back | Y / Page Down | V / End |

The [Making games presentation](https://ventilastation.protocultura.net/presentations/making-games/)
includes **Run this checkpoint** buttons. Each opens a complete runnable version
of Dream Garden containing the features introduced up to that slide. Early stages
start directly; later stages begin with the title screen. Press A to begin those.

To change code, create assets and save your own game, [set up the desktop emulator](desktop.md).
The desktop and browser run the same game API and circular rendering model.

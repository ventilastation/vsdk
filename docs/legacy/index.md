# Legacy documentation — obsolete for new games

New games use **VS2, API revision 2**. Follow [your first game](../vs2/tutorial/first-game.md).
The original sprites API remains available to run and maintain historical games.
Do not mix `vs2` and `ventilastation.sprites` in one game.

- [Original sprites API](sprites-api.md): maintenance of existing V1 games only.
- [Migration to current VS2](../vs2/migration.md): distinguish V1 from the removed VS2 prototype.
